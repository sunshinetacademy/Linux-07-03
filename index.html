1 افتتاحية: نفس العلم... لعبة جديدة 🎮

في المستوى التاني اخدنا Nmap و Wireshark على Windows، واستخدمنا أمر زي ipconfig لنعرف معلومات الشبكة. النهاردة هننقل نفس المهارات لعالم Linux — نفس الأفكار بالظبط، بس بأسماء وأدوات أقوى:

💡 سر مهم: اللي بيفهم المفهوم مش بيفرق معاه الأداة. إحنا بنكبر في الفهم — والأدوات بتتغير.

2 هويتك في الشبكة — بطاقة الرقم الشخصي 🪪

عشان الجهاز يقدر يتواصل، محتاج 4 معلومات أساسية — كلها زي بياناتك في المدرسة:

🏠

IP Address

عنوان بيتك في الشبكة — زي رقم شقتك. جيرانك (نفس الشبكة) كلهم عناوينهم شبه بعض: 192.168.1.x

🎭

Subnet Mask

بتحدد "الحي" اللي انت ساكن فيه — مين جارك ومين برة الحي. زي حدود الحي على الخريطة.

🚪

Gateway

البوابة الوحيدة الخارجة من حارتك للعالم الخارجي — عادةً الراوتر. لو مش رايح منه... مش هتخرج من الحتة دي!

📖

DNS

دليل التليفون بتاع الإنترنت — بترجم أسماء المواقع (google.com) لأرقام IPs. من غيره هتفكر المواقع بأرقام! 😵

🎓
مصطلحات النهاردة (احفظها بالإنجليزي — دي لغة الشغل):
بطاقة الشبكةNetwork Interface العنوانIP Address البوابةGateway خادم الأسماءDNS Server

🔌 الـ Interfaces — أطراف الجهاز اللي بتكلم منها

الاسممعناهمثال
eth0Ethernet — كابل الشبكة السلكي 🖼️اللاب توب موصول بكابل
wlan0WLAN — الواي فاي 📡الواي فاي في البيت
loLoopback — جهاز بيكلم نفسه! عنوانه دايمًا 127.0.0.1مفيد لاختبار الخدمات محليًا

💡 معلومة المحترفين: لما تشتغل على Kali في اختبار حقيقي، أول سؤال تسأله لنفسك: "أنا متوصل بإزاي؟ سلكي ولا واي فاي؟ ومن أنهي interface؟" — الجواب بيحدد كل خطواتك الجاية.

🧠 نقاش مع الطلبة: لو الـ Gateway وقع — تعرف تطلع للإنترنت؟ (لأ!) لو الـ DNS وقع؟ (هتقدر تبعت لكن مش هتعرف عنوان الموقع!) — وده اللي بيخلي محلل الأمن يسأل دايمًا: إيه نقاط الفشل المحتملة في الشبكة؟

🔐
تذكير بالقاعدة الذهبية: كل أوامر النهاردة بنستخدمها على شبكة اللاب المعزولة و على الإنترنت بشكل طبيعي (زي ping لمواقع مشهورة) — ممنوع نهائيًا فحص أو إزعاج أي شبكة أو جهاز خارجي. الفحص بيبقى بالأدوات في محاضرة Nmap الجاية، وداخل اللاب بس!

4 💻 الأوامر الأربعة الذهبية للشبكات

1️⃣ ip a — هويتي الكاملة

kali@sunshine
kali@sunshine:~$ ip a
1: lo: <LOOPBACK,UP> mtu 65536
inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST,UP> mtu 1500
inet 192.168.1.50/24 brd 192.168.1.255
# eth0 عنوانه 192.168.1.50 والشبكة /24

🔎 اقراها كده: UP = البطاقة شغالة ✅ | inet = عنوان IP4 | /24 = Subnet Mask 255.255.255.0 (افتكرنا المستوى الأول!)

2️⃣ ip route — إزاي أخرج من هنا؟

kali@sunshine:~$ ip route
default via 192.168.1.1 dev eth0
192.168.1.0/24 dev eth0 proto kernel
# default via = الـ Gateway: كل ما هتخرج بره، عدّي من 192.168.1.1

3️⃣ ping — "يلا جاوبني!" 📢

kali@sunshine:~$ ping -c 4 8.8.8.8
64 bytes from 8.8.8.8: icmp_seq=1 ttl=118 time=14.2 ms
64 bytes from 8.8.8.8: icmp_seq=2 ttl=118 time=13.8 ms
# time = زمن الذهاب والعودة (RTT) — كل ما يقل، كل ما كنت أسرع
kali@sunshine:~$ ping -c 2 192.168.1.200
From 192.168.1.50 icmp_seq=1 Destination Host Unreachable
# الجهاز ده مش موجود أو مقفول — أول علامة نلاحظها في الفحص!

💡 في Windows الـ ping بيوقف لوحده، في Linux لازم -c 4 (عدد المحاولات) أو Ctrl+C للإيقاف. ping بيجاوب على ICMP — افتكروا بروتوكول الوشاية ده من Wireshark؟ 😉

4️⃣ traceroute — تتبع رحلة الحزمة خطوة بخطوة 🗺️

kali@sunshine:~$ traceroute google.com
1 192.168.1.1 1.2 ms ← الراوتر بتاعنا (Gateway)
2 10.10.0.1 8.5 ms ← شبكة مزود الخدمة
3 41.62.x.x 12.1 ms ← شبكات أجنبية...
8 142.250.x.x 15.3 ms ← وصلنا Google! 🎉

💡 كل سطر = جهاز (Hop) الحزمة عدت منه. المحلل الأمني بيستخدمه يفهم المسار، والمهندس بيستخدمه يعرف فين وقع الاتصال!

5️⃣ بونص: cat /etc/resolv.conf — مين اللي بيترجم الأسماء؟

kali@sunshine:~$ cat /etc/resolv.conf
nameserver 192.168.1.1
# الـ DNS بتاعنا هو الراوتر نفسه — وبيعدي الترجمة لمزود الخدمة

💡 درس أمني صغير: لو حد غيّر الـ DNS بتاعك في ملف ده — ممكن يخطفك لمواقع مزيفة! (اسم الهجوم: DNS Spoofing — هنشوفه عملي في Wireshark قريب 🔮)

5 🏁 لعبة اليوم: سباق الـ Ping

🏁 القواعد

3 جولات — كل طالب/فريق عنده Terminal جاهز:

1

الجولة 1 — سرعة التنفيذ ⚡

المدرّس يعلن هدفًا (مثلًا: جهاز زميلك). أول واحد يعمل ping -c 4 له ويعرض النتيجة = نقطة

2

الجولة 2 — التخمين الذكي 🧠

قبل أي فحص: خمّن الـ RTT لـ 8.8.8.8 (أقرب للإجابة يكسب). بعدها جرب بالفعل — اللي تخمينه أدق = نقطة

3

الجولة 3 — عمق المسار 🗺️

شغّل traceroute لموقع مشهور وسجّل: كام Hop؟ إيه أكبر زمن في المسار؟ أدق تقرير = نقطة

🏆 الفائز بلقب "Network Scout" (كشاف الشبكة) لأسبوع!

🛠️ التمرين الرئيسي — خريطة شبكة اللاب 🗺️ (45 دقيقة)

🎯 السيناريو: أنت محلل شبكات — موّقن الشبكة دي

المدرّس حوّل اللاب لشبكة معزولة. مهمتك: اكتشف كل جهاز فيها وارسمها:

1

اجمع هويتك الأول

ip a و ip route — سجّل: عنوانك، الـ interface، الـ Gateway

2

اكتشف جيرانك

اعمل ping لعناوين قريبة من عنوانك (مثلًا لو عنوانك 192.168.10.20 — جرب .1 و .10 و .100 حتى تلاقي أجهزة حية)
💡 ملاحظة المحترفين: كل جهاز بيرد = جهاز حي في الشبكة. اللي مش بيرد = مش موجود أو مقفول

3

وثّق كل جهاز لقيته

في ملف nano network_map.txt سجّل لكل جهاز: عنوانه + زمن الـ ping + ملاحظتك (راوتر؟ جهاز زميل؟)

4

ارسم الخريطة 🎨

على ورقة أو على السبورة: ارسم أجهزة اللاب كلها كدواير، والـ Gateway في النص، ووصّل بخطوط. اكتب العناوين على كل جهاز

5

اختبر خريطتك

قارن خريطتك مع زمايلك — مين اكتشف أجهزة أكتر؟ إيه الأجهزة اللي اتفقوا عليها كلهم؟

🚀
التطوير الجاي (معلقة تشويقية): انتوا الـ ping ده جهاز جهاز — تعب، صح؟ 😅
في محاضرة Nmap الجاية، أمر واحد nmap -sn هيكتشف الشبكة كلها في ثواني. النهاردة اتعلمت اللي بتحته — والمحترف بيفاه الأداة قبل ما يستخدمها!

🏋️ تمرين إضافي (لو الوقت سمح): مفتش الاتصال 🔍

زميلك هيقطع كابل الشبكة (أو يطفى الواي فاي) — إنت مهمتك تشخيص المشكلة بالترتيب المحترف:

$ ip a # البطاقة لسه UP؟ فيه عنوان IP؟
$ ping -c 2 192.168.1.1 # الـ Gateway بيرد؟
$ ping -c 2 8.8.8.8 # الإنترنت الخارجي شغال؟
$ ping -c 2 google.com # الـ DNS بيترجم صح؟

🎯 الدرس: المحترف ما يقولش "النت مش شغال" — المحترف يقول فين بالظبط اتقطعت السلسلة! دي أشهر مهارة بيها يتوظف مهندس الدعم الفني.

5 🧠 اختبر نفسك — كويز تفاعلي

❓ سؤال 1: عنوان الـ Loopback lo دايمًا إيه؟
❓ سؤال 2: الـ Gateway هو...؟
❓ سؤال 3: ping رد بـ Destination Host Unreachable — معناه إيه؟
❓ سؤال 4: ping 8.8.8.8 شغال بس ping google.com فاشل — المشكلة فين؟

📌 خلاصة المحاضرة + الواجب

🪪 ip a — هويتك في الشبكة: العنوان + البطاقة + الحالة
🚪 ip route — الـ Gateway هو مخرجك الوحيد للعالم
📢 ping — اختبار الحياة والاتصال، والوقت time = سرعة الاستجابة
🗺️ traceroute — كل Hop في رحلة الحزمة، لحد وجهتها
📖 DNS — مترجم الأسماء لأرقام، وأخطر نقطة لو اتلاعب فيها
🔍 Troubleshooting — البطاقة ← Gateway ← إنترنت ← DNS بالترتيب

📝 الواجب المنزلي

  1. أنهي خريطة شبكة اللاب ولوّنها، وعلّم على الـ Gateway بدائرة مميزة ⭕
  2. في ملف homework3.txt: نفّذ سلسلة الـ Troubleshooting الأربعة على جهازك وسجّل نتيجة كل خطوة (نجاح ✅ / فشل ❌) واستنتج: شبكتك سليمة ولا فيها مشكلة؟
  3. ❓ سؤال التفكير: لما بتفتح يوتيوب، أول سؤال بيسأله جهازك لمين؟ (تلميح: مش ليوتيوب نفسها 😉)
  4. 🎁 اختياري: جرّب traceroute لموقعين مختلفين (مثلاً موقع مصري وموقع أمريكي) وقارن عدد الـ Hops — ليه بيختلف؟
